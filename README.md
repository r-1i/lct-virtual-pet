# Фини

Мобильная игра-тамагочи про финансовую грамотность для детей. Ребёнок заботится о питомце: отправляет его на
работу, покупает еду и средства для ухода, копит на мечту, планирует траты и проходит небольшие тесты про деньги.
Каждое решение что-то стоит, и игра мягко показывает, к чему оно приводит.

Подробное описание архитектуры, механик и сборки лежит в [DOCUMENTATION.md](DOCUMENTATION.md).

## Что нужно для запуска

- **Unity 6000.3.20f1** (Unity 6.3). Проект можно открыть и в более новой версии 6000.3.x, но проверяли на этой.
- Unity Hub.
- Модули платформ, если нужна сборка: Android Build Support (для APK) или Windows Build Support.
- Около 5 ГБ свободного места (папка `Library` создаётся при первом открытии).

## Локальный запуск

1. Склонировать репозиторий:
   ```
   git clone https://github.com/r-1i/lct-virtual-pet
   ```
2. В Unity Hub нажать **Add → Add project from disk** и выбрать папку с проектом.
3. Открыть проект версией **6000.3.20f1**. Первое открытие идёт долго (5-15 минут): Unity импортирует модели,
   звуки и пакеты.
4. Если в консоли есть ошибки про `DG.Tweening`, выполнить в меню
   **Tools → Demigiant → DOTween Utility → Setup DOTween** и нажать **Apply**. DOTween уже лежит в
   `Assets/Plugins/Demigiant`, его нужно только активировать.
5. Открыть сцену `Assets/Scenes/SampleScene.unity`. Вся игра находится в этой одной сцене.
6. В окне **Game** выбрать вертикальное разрешение, например 1080x2400 или 1284x2778 (игра рассчитана на
   портретный экран телефона).
7. Нажать **Play**.

При первом запуске покажется вступительная катсцена, затем создание питомца и обучение.

## Как быстро посмотреть всё

В игре есть отладочное меню: **шестерёнка (Настройки) → Debug Menu**. Там можно добавить монеты, поменять
показатели питомца, промотать день вперёд, закончить смену, сдать тест и так далее. Это удобно, чтобы не ждать
реального времени: смены длятся от 1 до 9 часов, а новый день в игре наступает вместе с настоящим календарным днём.

Начать игру с нуля можно так: **Настройки → Профиль родителя** (нужно решить пример) **→ Удалить аккаунт**.

## Сборка на Android

1. **File → Build Profiles**, выбрать **Android**, нажать **Switch Platform**.
2. Убедиться, что в списке сцен есть `Assets/Scenes/SampleScene.unity`.
3. Нажать **Build** и выбрать папку для APK.

Сборка под Windows делается так же через профиль **Windows**.

## Где лежат сохранения

Прогресс хранится в `save.json` в `Application.persistentDataPath`. На Windows это
`%USERPROFILE%\AppData\LocalLow\DefaultCompany\LCTHack_Tamagochi\`. Рядом лежит папка `saves` со снимками по
дням и письмами. Чтобы начать заново в редакторе, можно просто удалить эти файлы.
