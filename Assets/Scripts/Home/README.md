# Zone System — установка

Система из 4 скриптов: по нажатию кнопки камера и персонаж **мгновенно телепортируются**
в точки нужной зоны, персонаж играет анимацию действия. Если персонаж занят (`Busy`) —
телепортируется только камера.

## Файлы
- `Zone.cs` — описание одной зоны (точка камеры, точка персонажа, анимация действия)
- `CharacterMotor.cs` — состояние персонажа `Idle / Busy` + мгновенный телепорт
- `CameraZoneRig.cs` — мгновенный телепорт камеры на точку зоны
- `ZoneManager.cs` — связывает кнопки UI, камеру и персонажа

## Шаг 1 — персонаж
1. На корневой GameObject персонажа (у которого уже настроен `Animator`) добавь компонент `CharacterMotor`.
2. В поле **Animator** перетащи компонент Animator персонажа (может быть на дочернем объекте с мешем — это ок, поле не обязано быть на этом же GameObject).

## Шаг 2 — камера
1. Создай пустой GameObject `CameraRig` в сцене (или используй существующий родитель камеры).
2. Добавь на него `CameraZoneRig`.
3. В поле **Camera Transform** перетащи transform самой Camera (Reset() попробует подставить `Camera.main` автоматически, если оставить пустым и нажать правой кнопкой → Reset на компоненте).

## Шаг 3 — точки зон
Для каждой зоны (кормление, сон, мойка и т.д.) создай в сцене **два пустых GameObject**:
- `CamPoint_<Название>` — поставь его туда, где должна мгновенно оказаться камера (важны и позиция, и поворот)
- `CharPoint_<Название>` — поставь туда, куда должен мгновенно телепортироваться персонаж

Удобно держать их внутри пустого родителя `ZonePoints`, чтобы не мешались в иерархии.

## Шаг 4 — ZoneManager
1. Создай пустой GameObject `ZoneManager`, добавь компонент `ZoneManager`.
2. Заполни ссылки **Character** и **Camera Rig** (перетащи объекты из шагов 1-2).
3. В массиве **Zones** — по одному элементу на каждую кнопку:
   - `Id` — просто для читаемости (например "Feed")
   - `Camera Target` → соответствующий `CamPoint_...`
   - `Character Target` → соответствующий `CharPoint_...`
   - `Action Trigger` → имя **Trigger**-параметра в Animator Controller (например "Eat", "Sleep", "Wash"). Если оставить пустым — персонаж просто появится в Idle.
   - `Action Duration` → сколько секунд персонаж будет "занят" (Busy) после начала анимации действия, прежде чем сможет снова телепортироваться в другую зону.
   - `Face Target Rotation` → если включить, персонаж телепортируется с поворотом (только по Y), взятым у `CharPoint_...`. Если выключено — поворот персонажа не трогается вообще (остаётся таким, каким был до телепорта).

Порядок элементов в массиве — это и есть индексы зон (0, 1, 2, 3, 4), которые используются на шаге 5.

## Шаг 5 — кнопки
На каждой из 5 нижних кнопок (`Button` компонент):
1. `OnClick ()` → `+`
2. Перетащи GameObject `ZoneManager` в слот объекта
3. Функция: `ZoneManager → GoToZone (int)`
4. В появившемся поле int впиши индекс зоны из массива Zones (0 для первой кнопки, 1 для второй и т.д.)

## Как это работает в игре
- Нажатие кнопки → камера **всегда** мгновенно телепортируется на `cameraTarget` этой зоны (position + rotation).
- Если персонаж **не занят** — он тоже мгновенно телепортируется на `characterTarget`, играет `actionTrigger` и уходит в `Busy` на `actionDuration` секунд.
- Если персонаж **занят** — он остаётся на месте и доигрывает текущее действие, телепортируется только камера.

## Если камера "смотрит не туда"
У `CamPoint_...` важны оба параметра — и Position, и Rotation, потому что камера ставится
ровно в transform точки. Проверь в инспекторе `CamPoint_...`, что Rotation отличается
от зоны к зоне (если все точки создавались копированием, легко забыть повернуть очередную).

## Точная синхронизация анимации (опционально)
Если `actionDuration` не совпадает по времени с реальной длиной клипа — можно вместо таймера
использовать **Animation Event**: в конце клипа действия добавь событие, вызывающее
`CharacterMotor.OnActionAnimationEvent_Complete()`. Тогда `actionDuration` в инспекторе можно
поставить с запасом (как safety net), а реально Busy снимется по событию.
